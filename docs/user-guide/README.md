## 简介

Game Asset Studio 是一款专为游戏开发者设计的素材管理工具。它可以帮助您：

- 从多个网站搜索游戏素材
- 批量下载素材
- 管理本地素材库
- 导出素材到游戏引擎

## 安装

### 系统要求

- Windows 10/11 (64位)
- 至少 4GB 内存
- 100MB 磁盘空间

### 安装步骤

1. 下载最新版本的安装程序
2. 双击运行安装程序
3. 按照提示完成安装
4. 启动 Game Asset Studio

## 界面介绍

### 主界面

应用启动后，您会看到左侧有一个侧边栏，包含以下功能：

- **搜索** - 搜索网络素材
- **素材库** - 管理已保存的素材
- **设置** - 配置应用参数

### 搜索页面

搜索页面包含：

- 搜索框 - 输入关键词
- 来源筛选 - 选择搜索网站
- 结果展示 - 网格或列表视图

### 素材库页面

素材库页面包含：

- 搜索框 - 搜索本地素材
- 筛选按钮 - 全部/收藏/已下载
- 视图切换 - 网格/列表视图

## 搜索素材

### 基本搜索

1. 点击左侧"搜索"图标
2. 在搜索框输入关键词（如"pixel art"、"character"）
3. 点击"搜索"按钮或按回车键
4. 等待搜索结果

### 来源筛选

您可以选择搜索哪些网站：

- **itch.io** - 最大的独立游戏素材市场
- **OpenGameArt** - 开源游戏素材社区
- **Kenney** - 高质量免费素材

点击来源按钮可以启用/禁用该网站。

### 浏览结果

搜索结果以卡片形式展示：

- 预览图
- 素材名称
- 作者
- 来源网站
- 价格

将鼠标悬停在卡片上可以看到操作按钮。

## 下载素材

### 下载方法

1. 将鼠标悬停在素材卡片上
2. 点击"下载"按钮（向下箭头图标）
3. 等待下载完成

### 下载位置

默认下载位置：`D:\GameAssetStudio\downloads\`

您可以在设置中修改下载路径。

### 下载状态

- 蓝色 - 可下载
- 黄色旋转 - 下载中
- 绿色勾号 - 已下载

## 素材库管理

### 保存到素材库

1. 将鼠标悬停在素材卡片上
2. 点击"保存"按钮（书签图标）
3. 素材将保存到本地数据库

### 查看素材库

1. 点击左侧"素材库"图标
2. 查看已保存的素材

### 筛选素材

使用顶部的筛选按钮：

- **全部** - 显示所有素材
- **收藏** - 显示收藏的素材
- **已下载** - 显示已下载的素材

### 搜索本地素材

在素材库页面的搜索框输入关键词，可以搜索本地素材。

### 收藏素材

将鼠标悬停在素材卡片上，点击"收藏"按钮（星星图标）。

### 删除素材

将鼠标悬停在素材卡片上，点击"删除"按钮（垃圾桶图标）。

## 设置

### 存储设置

- **素材存储路径** - 设置下载素材的保存位置

### API 配置

- **itch.io API Key** - 输入您的 itch.io API Key（可选）

### 素材来源

选择默认启用的素材来源网站。

### 导出设置

选择导出素材时的默认格式：

- **Unity** - SpriteSheet + .meta 文件
- **Godot** - SpriteFrames 资源
- **通用** - PNG 序列帧

## 常见问题

### Q: 搜索没有结果？

A: 请检查：
1. 网络连接是否正常
2. 关键词是否正确
3. 是否启用了对应的素材来源

### Q: 下载失败？

A: 可能原因：
1. 网络连接问题
2. 服务器暂时不可用
3. 文件已被删除

请稍后重试。

### Q: 如何修改下载位置？

A: 在设置页面的"存储设置"中修改"素材存储路径"。

### Q: 素材保存在哪里？

A: 素材元数据保存在本地数据库中，文件保存在下载目录中。

数据库位置：`%APPDATA%\com.game-asset-studio.app\assets.db`

### Q: 如何导出素材到 Unity？

A: 
1. 在设置中选择导出格式为"Unity"
2. 选择要导出的素材
3. 点击导出按钮
4. 将导出的文件复制到 Unity 项目的 Assets 目录

### Q: 支持哪些图片格式？

A: 支持 PNG、JPG、WebP、GIF 等常见格式。

### Q: 如何更新应用？

A: 
1. 下载最新版本的安装程序
2. 运行安装程序，它会自动覆盖旧版本
3. 您的数据不会丢失
